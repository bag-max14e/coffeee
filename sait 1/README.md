# Суть Кофе — сайт-концепт для кав’ярні в Дніпрі

Односторінковий сайт для спешелти-кав’ярні: тепла «паперова» палітра, велика
серифна типографіка, фото, плавні анімації та повністю адаптивна верстка.

## Як відкрити

Достатньо відкрити `index.html` у браузері — жодних збірок і залежностей немає.

Для локального сервера (зручніше для перевірки):

```bash
python3 -m http.server 8000
```

Потім відкрити <http://localhost:8000>.

## Що всередині

- `index.html` — вся розмітка лендінгу;
- `styles.css` — стилі, палітра й адаптивність;
- `script.js` — мобільне меню, таби меню, лайтбокс галереї, статус «зараз
  відчинено», scroll-reveal, паралакс hero-фото;
- `assets/favicon.svg` — іконка сайту.

### Секції

1. Hero з аркою-фото та карткою «сьогодні у фільтрі»;
2. Біжуча строка;
3. Про нас + цифри;
4. Меню з категоріями «Еспресо / Фільтр / Не кава»;
5. Ритуал приготування (4 кроки);
6. Галерея з лайтбоксом;
7. Відгуки та рейтинг;
8. Контакти, графік і стилізована мапа;
9. Футер.

## Що змінити перед публікацією

Дані нижче — **демонстраційні**. Замініть їх на реальні:

- адреса: `вул. Старокозацька, 24, Дніпро` (у шапці, контактах, футері,
  посиланнях Google Maps);
- телефон: `+380 67 123 45 67` (усі `tel:`-посилання);
- email: `hello@sut.coffee`;
- Instagram: в демо вказано `instagram.com/sut.coffee` — замініть на реальний
  акаунт;
- графік: Пн–Пт 08:00–21:00, Сб–Нд 09:00–22:00 (він же використовується
  скриптом для статусу «відчинено/зачинено»);
- ціни та описи позицій меню.

Фотографії підключені з Unsplash за прямими посиланнями (демо-контент).
Для продакшену краще замінити їх на власні фото кав’ярні: достатньо оновити
`url(...)` у відповідних класах `styles.css` (`.hero-photo`, `.about-main`,
`.menu-card`, `.g-photo-*`) та `data-full` у галереї.

## Технічні деталі

- Без фреймворків і білд-кроків: HTML + CSS + ванільний JS.
- Шрифти: Cormorant Garamond + Manrope (Google Fonts), з системними
  фолбеками.
- Доступність: семантична розмітка, skip-link, фокус-стилі, ARIA для табів,
  керування з клавіатури, підтримка `prefers-reduced-motion`.
- Адаптивність: контрольні точки 1120 / 1040 / 900 / 720 / 560 / 400 px.
